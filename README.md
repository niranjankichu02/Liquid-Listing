## 💧 Liquid Listings

**Hackathon Useless Project 3.0**

Premium, 100% unstable real estate made of liquid food.

### 📖 Description

Liquid Listings is a hilariously useless web app that generates blueprints for properties constructed entirely from fluid food items. Why build with concrete when you can build with Rasam?

### ⚙️ Workflow

1. **Welcome Phase:** The user initiates the architectural process.
2. **Data Input:** The user selects or types a liquid food item (or uploads an image to theoretically "scan" it).
3. **Environmental Setup:** The user adjusts a Viscosity slider (thickness) and selects current Weather conditions (Sunny, Rainy, Freezing).
4. **Processing:** A custom CSS-animated liquid loading screen simulates "fluidity analysis."
5. **Result Generation:** The app outputs a generated blueprint featuring Durability (calculated from viscosity), Evaporation timeline (calculated from weather), and randomized Pest statuses.

### 💻 Technical Details

* **Frontend UI:** Built with pure HTML5 and CSS3. Implements a modern Glassmorphism (frosted glass) aesthetic, gradient backgrounds, and custom CSS keyframe animations for the loader.
* **Logic Engine:** Vanilla JavaScript. Handles event listening, DOM manipulation, simple mathematical calculations for stat outputs, and array randomizers for dynamic text generation.
* **Architecture:** Zero dependencies and no external APIs. It mimics a Single Page Application (SPA) by toggling CSS classes (`display: none` to `display: block`) to transition smoothly between screens without page reloads.
